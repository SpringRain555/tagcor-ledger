## 視覺主題

- 介面固定使用深色主題；目前不提供主題切換。
- 側邊欄、分頁、表格、下拉選單、清單、彈窗與狀態列都必須維持深色樣式。
- 主要操作使用藍色視覺層級；危險操作例如作廢、刪除、還原、重製使用紅色視覺層級。
- 新增 UI 元件時，若用途不同，需指定 objectName，避免全域 QSS 影響其他元件。
- UI 字體採本機 fallback：`Segoe UI Variable`、`Segoe UI`、`Microsoft JhengHei UI`、`Microsoft JhengHei`、`Noto Sans TC`。

## 快速記帳

支出/收入流程：

```text
流向 → 帳戶 → 類別 → 項目 → 時間 → 金額 → 備註
```

轉帳流程：

```text
流向 → 來源帳戶 → 轉入帳戶 → 時間 → 金額 → 備註
```

選擇轉帳時隱藏類別與項目，顯示轉入帳戶。來源與目的帳戶不可相同。

## 交易紀錄

- 支援文字、日期、帳戶、類別與狀態篩選。
- 支援上一頁/下一頁。
- 支出與收入可直接編輯。
- 轉帳使用替換流程：新轉帳建立成功後，舊轉帳在同一資料庫 transaction 作廢。
- 複製交易只預填快速記帳，不直接入帳。

## 操作設定

- 帳戶、類別、項目：新增、重新命名、封存、恢復、刪除未使用。
- 模板與週期排程：建立、編輯、封存、產生到期待確認。
- 刪除只適用未被引用的設定項；被歷史資料引用時顯示繁中錯誤並建議封存。

## 系統設定

- 一般設定：預設帳戶、預設流向、每頁筆數、餘額盤點提醒。
- 資料路徑：設定記帳資料路徑與備份路徑，提供切換既有資料與搬移目前資料。
- 備份與還原：建立備份、驗證、還原、選擇外部備份資料夾、CSV 匯出。
- 重製與還原：重製目前記帳資料，不刪除備份資料夾。

備份只由使用者手動按鈕觸發。還原/重製前保護備份必須勾選才執行。

## 餘額盤點

- 可選帳戶、時間、目前金額與備註。
- 顯示最近盤點、預期金額、實際金額與未解釋差額。
- 顯示差額期間內交易，方便補記或檢查。

## 待確認

- 修改後確認入帳。
- 略過。
- 批次確認仍有效項目。
- 顯示失效原因，例如帳戶已封存、類別已封存、尚未填寫金額。
