# UI 操作流程

## 導覽

側邊導覽固定包含：快速記帳、待確認、交易紀錄、帳戶、分類、模板與排程、備份與匯出、設定。待確認項目在導覽列顯示數量。

## 快速記帳

一般交易依序選擇：

```text
流向 → 帳戶 → 分類 → 細項 → 時間 → 對象／商家 → 金額 → 備註
```

選擇轉帳時隱藏分類與細項，改顯示轉入帳戶。來源與目的帳戶不可相同。

## 交易紀錄

- 每頁依設定顯示 20、50 或 100 筆。
- 可組合文字、日期、帳戶、分類與狀態篩選。
- 上一頁與下一頁使用 keyset cursor，不以 offset 掃描。
- 一般交易直接編輯；轉帳使用原子替換。
- 可複製到快速記帳並改用目前時間。
- 作廢需二次確認。

## 模板與排程

- 模板套用只預填快速記帳，不直接入帳。
- 排程支援日、週、月、年、間隔倍數及結束日期。
- 啟動時及使用者按下產生時，建立到期待確認項目。
- 單次超過 366 期時提示繼續產生。

## 待確認

- 可修改後確認入帳、略過或批次確認有效項目。
- 金額未填、帳戶或分類失效時顯示原因。
- 排程修改不回寫既有待確認 snapshot。

## 備份與還原

- 列出並驗證內建備份。
- 可選擇含 `backup_manifest.json` 的外部資料夾。
- 還原前先備份目前資料庫；checksum、完整性或 schema 版本不符時拒絕。

## 快捷鍵

- `Ctrl+N`：切回快速記帳並聚焦金額。
- `Ctrl+S`：儲存目前快速記帳表單。
- `Esc`：清除表單。

## 文字規則

- 所有主要訊息使用繁體中文。
- 「對象／商家」與「備註」不得混用。
- 日期顯示為 `yyyy/MM/dd HH:mm`。
