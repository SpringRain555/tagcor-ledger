# UI 操作流程

## 導覽

側邊導覽固定包含：快速記帳、交易紀錄、帳戶、分類、備份與匯出、設定。

## 快速記帳

一般交易依序選擇：

```text
流向 → 帳戶 → 分類 → 細項 → 時間 → 對象／商家 → 金額 → 備註
```

選擇轉帳時隱藏分類與細項，改顯示轉入帳戶。來源與目的帳戶不可相同。

## 交易紀錄

- 每頁最多 50 筆。
- 可搜尋對象、備註、分類與帳戶。
- 下一頁使用 keyset cursor。
- 作廢需二次確認。

## 快捷鍵

- `Ctrl+N`：切回快速記帳並聚焦金額。
- `Ctrl+S`：儲存目前快速記帳表單。
- `Esc`：清除表單。

## 文字規則

- 所有主要訊息使用繁體中文。
- 「對象／商家」與「備註」不得混用。
- 日期顯示為 `yyyy/MM/dd HH:mm`。
