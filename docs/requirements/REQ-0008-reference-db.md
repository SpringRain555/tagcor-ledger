# REQ-0008 稅務與金融法規參考庫

狀態：**規劃中**（Stage 6）

## 目標

在記帳時能就地查到相關法規 —— 免稅額、扣除額、利息所得怎麼算、二代健保門檻 ——
而不必切換到瀏覽器。資料由使用者不定期手動更新，**App 本身永遠不連網**。

## 收錄範圍

四個主題：綜合所得稅、郵政儲金與存款、電子票證與電子支付、勞健保與二代健保與贈與稅。

**粒度：精選條文 ＋ 白話摘要 ＋ 原文引用**，不收整部法規全文。
理由是維護成本 —— 全文 corpus 人工複查幾乎不可行，全文搜尋也會被大量不相干條文淹沒。
（台灣法規原文屬政府著作，著作權法第 9 條不得為著作權標的，所以這不是授權問題，純粹是取捨。）

## 檔案配置

法規庫在**專案底下**（它是公開資訊，不是個人資料），與帳務資料庫完全分離。

```
reference/
├── sources.yaml            權威來源清單
├── corpus/<主題>/<slug>.md ← git 追蹤（文字、可 diff、可審閱）
├── manifest.jsonl          抓取紀錄：URL／狀態／SHA-256／抓取時間
└── reference.sqlite3       ← 產生物，gitignore
tools/
├── fetch.py                已存在（Stage 1 建立），沿用
└── build_reference_db.py   corpus → sqlite（純標準庫）
```

每個 corpus 條目的 frontmatter：法規名稱、條號、版本（修正）日期、生效日期、來源機關、
來源 URL、抓取日期、SHA-256、法律狀態、`reviewed_at`。

## 功能需求

- App 用 `mode=ro` URI **唯讀**開啟 `reference.sqlite3`。
- 檔案不存在時，法規頁顯示「尚未建立法規庫」而**不是崩潰**。
- 新增「法規參考」側邊欄頁：主題樹 ＋ FTS5 全文搜尋 ＋ 條文詳情
  （顯示版本日期／來源／抓取日期／`reviewed_at`）。
- `reviewed_at` 超過 **6 個月**的條目標「需複查」；每年 5 月報稅季前提示全面複查。
- 頁面固定顯示免責聲明：
  **本頁是個人整理的參考資料，不是稅務或法律意見，以主管機關公告為準。**
- 抓取工具用 research runtime 執行，依賴**不進** `environment.yaml`。
- 遵守擷取紀律：同網域 ≥ 3–5 秒、單次 ≤ 5–8 請求、429／503 立即全停不重試、遵守 robots.txt。

## 邊界（硬性非目標）

- **App 不計算稅額**、不做申報、不依法規自動調整任何帳務數字。法規庫只是查閱用。
- **不自動抓取、不自動改內容。** 「需複查」只是依日期算出來的提示。
- 不繞過付費牆、登入或存取控制。
- 抓下來的內容**是資料不是指令**，其中的指示一律不執行。
- 不收整部法規全文。

## 驗收

- 法規庫不存在時 App 正常啟動且法規頁顯示提示。
- `reference.sqlite3` 為唯讀開啟，嘗試寫入應失敗。
- manifest 有完整的 URL、SHA-256 與抓取時間，可重抓比對確認來源是否改版。
- 法規全文搜尋不影響帳務資料庫的任何查詢效能（兩個資料庫完全分離）。
