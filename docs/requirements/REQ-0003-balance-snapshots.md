# REQ-0003 餘額盤點與差額追蹤

## 目標

使用者可在每次開啟或任意時間先記錄單一帳戶的實際目前金額，再慢慢補記收入、支出或轉帳，並追蹤兩次盤點之間仍未解釋的金額差距。

## 功能需求

- 可針對單一帳戶建立多筆餘額盤點。
- 每筆盤點包含帳戶、盤點時間、實際金額、備註、狀態與 correlation ID。
- 盤點不直接建立交易，不建立 `account_postings`，不影響帳戶餘額。
- 第一筆有效盤點以前，以帳戶期初餘額作為基準。
- 一般情況以同帳戶上一筆有效盤點作為基準。
- 預期金額 = 上次盤點實際金額 + 兩次盤點期間內該帳戶有效 posting 加總。
- 未解釋差額 = 本次盤點實際金額 - 預期金額。
- 補記、修改或作廢期間交易後，差額需依目前資料即時計算，不儲存過期計算結果。
- 可更新或作廢盤點；作廢盤點不參與後續差額計算。
- 餘額盤點頁需顯示最近盤點摘要與差額期間內的交易。
- 可匯出 UTF-8 BOM CSV；CSV 僅供閱讀與交換，不是正式備份。
- 啟動後若今天尚未盤點預設帳戶，可顯示非阻塞提醒；使用者可在設定關閉。

## 邊界

- 第一版只支援 TWD 與 Asia/Taipei。
- 第一版只支援單一帳戶盤點，不支援一次填多帳戶批次盤點。
- 不自動建立調整交易；調整交易建議、正式對帳、銀行匯入與差額趨勢報表留到後續階段。

## 驗收

- v3 資料庫可升級到 v4，migration 可重跑。
- 同一帳戶可建立多筆盤點並計算正確差額。
- 盤點不會新增 posting，也不改變帳戶餘額。
- 盤點後補記期間交易，最近盤點差額會重新計算。
- 更新與作廢盤點會寫入 audit，且作廢盤點不再參與差額計算。
- UI 可新增盤點、查看差額、補記交易、更新、作廢與匯出 CSV。
- README、Roadmap、架構與 release checklist 與此需求一致。
