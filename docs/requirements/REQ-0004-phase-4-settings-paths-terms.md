# REQ-0004：Phase 4 設定、路徑、用詞與欄位精簡

## 目標

Phase 4 將 UI 設定整理為「操作設定」與「系統設定」，讓記帳資料可與專案分離，並移除不再需要的「對象／商家」欄位。

## 功能需求

1. 側邊欄固定為：快速記帳、餘額盤點、待確認、交易紀錄、操作設定、系統設定。
2. 操作設定管理帳戶、類別/項目、模板與週期排程。
3. 系統設定管理一般偏好、資料路徑、備份與還原、重製與還原。
4. UI 顯示「類別／項目」，不得再使用「分類／細項」。
5. 快速記帳欄位為：流向、帳戶、類別、項目、時間、金額、備註。
6. 完全移除「對象／商家」與 payee runtime 功能。
7. `ledger_dir` 與 `backup_dir` 必須可分開設定，且不得相同或互相包含。
8. 備份只在使用者手動建立時執行。
9. 還原與重製前的保護備份必須由使用者明確勾選。
10. 重製只移除目前記帳資料庫並重新初始化預設資料，不刪除備份資料夾。
11. 帳戶、類別、項目可刪除未使用項；已被引用者只能封存。
12. 預設帳戶不可刪除，必須先切換預設帳戶。

## Schema 需求

Schema v5：

- 移除 `payees`。
- 移除 `transactions.payee_id` 與 `transactions.payee_name_snapshot`。
- 移除模板、排程與待確認項目的 `payee_name`。
- 重建 `transaction_fts`，只搜尋備註、類別/項目與帳戶。
- 移除 `startup_backup` 與 `last_startup_backup_date` 設定使用。

## 驗收

- `pytest` 通過。
- Ruff 零錯誤。
- strict mypy 通過。
- UI smoke 可在 offscreen 模式啟動。
- 使用者可在 README 找到資料路徑、備份、還原、重製與操作設定說明。
