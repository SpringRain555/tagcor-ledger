# REQ-0002 Phase 1–2

## Phase 1

- 交易列表支援日期、帳戶、分類、狀態與文字組合篩選。
- 頁面筆數為 20、50 或 100，支援上一頁與下一頁 keyset navigation。
- 轉帳修改採原子替換並保存 `replaces_transaction_id`。
- 帳戶及分類可恢復，重名或上層未恢復時拒絕。
- 可列出、驗證及還原內建或外部 manifest 備份；還原前自動備份。
- 設定支援預設帳戶、預設流向、頁面筆數與啟動備份規則。
- Schema v2 加入轉帳替換關聯。
- 移除 PyQt6、TagPath、CSV/JSON runtime、legacy importer 與舊測試。

## Phase 2

- Schema v3 加入模板、週期排程及待確認項目。
- 模板支援收入、支出、轉帳，金額可空；套用只預填表單。
- 交易可複製到快速記帳並使用目前時間。
- 對象／商家最多顯示 20 筆近期使用建議。
- 排程支援日、週、月、年、間隔及結束日期，月末自動 clamp。
- 排程只產生待確認 snapshot；修改排程不變更既有 snapshot。
- 每次最多產生 366 期，可重複操作直到補齊所有漏期。
- 待確認可修改後入帳、略過及批次確認有效項目。
- 程式啟動時產生到期項目，不建立背景服務。

## 固定邊界

- 幣別為 TWD，時區為 Asia/Taipei。
- 不包含預算、拆分交易 UI、正式對帳、多幣別、銀行同步及 Installer。
