# TagCor Ledger Roadmap

## 已完成

### Phase 0–2：穩固核心與模板排程

- SQLite 主資料庫、WAL、foreign keys、migration registry。
- 帳戶、類別/項目、交易、posting、allocation、audit。
- 收入、支出、轉帳、編輯、作廢、替換轉帳。
- 交易列表篩選與 keyset pagination。
- 手動備份、備份驗證、還原、CSV 匯出。
- 模板、週期排程、待確認項目、批次確認。

### Phase 3：餘額盤點與差額追蹤

- Schema v4 `balance_snapshots`。
- 單一帳戶可多次盤點。
- 盤點不入帳、不建立 posting。
- 依上一筆盤點與期間交易自動計算未解釋差額。
- 支援盤點新增、編輯、作廢、列表與 CSV 匯出。
- 啟動後可提醒今日尚未盤點預設帳戶。

### Phase 4：操作/系統設定、路徑分離與用詞精簡

- 側邊欄重整為快速記帳、餘額盤點、待確認、交易紀錄、操作設定、系統設定。
- 操作設定整合帳戶、類別/項目、模板與週期排程。
- 系統設定整合一般設定、資料路徑、備份與還原、重製與還原。
- 新增外部系統路徑設定：`ledger_dir` 與 `backup_dir`。
- 備份改為純手動；移除啟動自動備份。
- 重製目前記帳資料，不刪除備份。
- 帳戶、類別、項目支援刪除未使用。
- UI 用詞統一為「類別／項目」。
- 移除 payee/對象商家欄位與 FTS 依賴。

## 後續候選 Phase

### Phase 5：報表與洞察

- 月度/年度收入支出趨勢。
- 類別/項目占比。
- 帳戶餘額走勢。
- 盤點差額統計與異常提示。
- 匯出報表 CSV。

### Phase 6：正式對帳與調整建議

- 對帳期間狀態。
- 對帳完成鎖定。
- 未解釋差額的調整交易建議。
- 對帳報告。

### Phase 7：輸入效率

- 常用項目排序。
- 最近使用組合。
- 快速搜尋/鍵盤導向輸入。
- 可選輸入規則與自動填值。

### Phase 8：資料可攜與封裝

- Windows Installer。
- 備份匯入/匯出精靈。
- 更完整的資料健康檢查。

## 延後項目

- 多幣別與匯率。
- 銀行同步。
- 預算。
- 拆分交易 UI。
- 雲端同步。
