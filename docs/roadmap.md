# TagCor Ledger Roadmap

## 已完成

### Phase 0–2：穩固核心與模板排程

- SQLite 主資料庫、WAL、foreign keys、migration registry。
- 帳戶、類別/項目、交易、posting、allocation、audit。
- 收入、支出、轉帳、編輯、作廢、替換轉帳。
- 交易列表篩選與 keyset pagination。
- 手動備份、備份驗證、還原、CSV 匯出。
- 模板、週期排程、待確認項目、批次確認。

### Phase 3：餘額盤點與差額追蹤

- Schema v4 `balance_snapshots`。
- 單一帳戶可多次盤點。
- 盤點不入帳、不建立 posting。
- 依上一筆盤點與期間交易自動計算未解釋差額。
- 支援盤點新增、編輯、作廢、列表與 CSV 匯出。
- 啟動後可提醒今日尚未盤點預設帳戶。

### Phase 4：操作/系統設定、路徑分離與用詞精簡

- 側邊欄重整為快速記帳、餘額盤點、待確認、交易紀錄、操作設定、系統設定。
- 操作設定整合帳戶、類別/項目、模板與週期排程。
- 系統設定整合一般設定、資料路徑、備份與還原、重製與還原。
- 新增外部系統路徑設定：`ledger_dir` 與 `backup_dir`。
- 備份改為純手動；移除啟動自動備份。
- 重製目前記帳資料，不刪除備份。
- 帳戶、類別、項目支援刪除未使用。
- UI 用詞統一為「類別／項目」。
- 移除 payee/對象商家欄位與 FTS 依賴。

### Phase 4.1：深色主題、UI 可讀性與文件重整

- PySide6 介面統一為專業深藍深色主題。
- 新增 `apply_dark_theme(app)` 作為主題入口，統一設定 `Fusion` style、字體、palette 與 QSS。
- 補齊分頁、下拉選單、表格、清單、狀態列、訊息框、捲軸與按鈕角色樣式。
- 側邊欄與一般清單分離：側邊欄使用 `sidebarNavigation`，備份清單使用 `backupList`，避免全域 `QListWidget` 樣式污染。
- 字體採本機 fallback，不打包字型檔。
- README、AGENTS、Roadmap、Requirements、Architecture 與 Release Checklist 已整理成一致規格。

## 使用者提出、尚未排程的項目

**2026-08-18 實機試用後提出。** 兩項都不影響九月上線（記帳功能已可用），所以不插隊到
Stage 4–7，但也不要放到「延後項目」裡當作不做 —— 它們是明確要做的，只是還沒排時間。

### UI-1：時間欄位要能用日曆與時鐘子視窗選

現況：`QDateTimeEdit` 已經有 `setCalendarPopup(True)`，所以**日期**點得出日曆，
但**時間**只能手打或用上下鍵。使用者要的是時、分也能用彈出式介面點選。

要做的事：時間部分改成可彈出的時鐘／滾輪選擇器，或提供「現在」「整點」這類快捷。
影響 `ui/pages/quick_entry.py`、`ui/pages/balance_snapshot.py` 與兩個編輯對話框 ——
**做的時候要一起改，不要只改快速記帳**，否則同一種欄位在不同頁面操作方式不一樣。

### UI-2：配色重做，要乾淨清楚

現況：Phase 4.1 的深色主題偏深藍，使用者評為「很醜」。

要做的事：**先看有規模的產品怎麼配色再動手**，不要憑感覺調。Stage 1 已經抓過
17 個來源（見 `docs/research/`），但當時的焦點是互動設計不是視覺，所以需要補一次
針對配色的調查 —— 中性灰階為底、彩色只用在需要注意的地方，是這類工具型介面的通例，
但要有證據不是印象。

範圍是 `ui/theme.py` 與 `resources/styles.qss`（419 行、64 個 selector），
`tests/unit/test_resources.py` 與 `tests/ui/test_main_window.py` 裡有寫死的色碼與
selector 名稱，改配色要同步更新。

## 後續候選 Phase

### Phase 5：報表與洞察

- 月度/年度收入支出趨勢。
- 類別/項目占比。
- 帳戶餘額走勢。
- 盤點差額統計與異常提示。
- 匯出報表 CSV。

### Phase 6：正式對帳與調整建議

需求與設計已寫在 [REQ-0010](requirements/REQ-0010-reconciliation-gap.md)，含市場調查的證據。
**排定 2026-10 月底依實際使用經驗重新評估**，不預先加欄位。

- 交易的已核對狀態（郵局能逐筆對存摺，現金不能）。
- 對帳完成鎖定。
- 未解釋差額轉成調整交易 —— **做成一顆明確的按鈕，不是自動行為**。
- 對帳報告。

### Phase 7：輸入效率

- 常用項目排序。
- 最近使用組合。
- 快速搜尋/鍵盤導向輸入。
- 可選輸入規則與自動填值。

### Phase 8：資料可攜與封裝

- Windows Installer。
- 備份匯入/匯出精靈。
- 更完整的資料健康檢查。
